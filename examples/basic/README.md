# Basic Example

This is a basic example of using elysia-nest to create a simple API.

## Running the example

```bash
# Install dependencies
bun install

# Run the example
bun run dev
```

## What's included

- A simple module structure
- A controller with a GET endpoint
- A service that returns data
- Basic dependency injection

## Endpoints

- `GET /api/hello` - Returns a hello world message
